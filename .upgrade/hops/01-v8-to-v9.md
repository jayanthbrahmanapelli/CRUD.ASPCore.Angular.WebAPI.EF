## Framework notes
- Run the update command first: it applies Angular's own migrations. Only then fix what is left by hand.
- If install fails on peer dependencies, retry with --legacy-peer-deps (npm 7+) before changing versions.
- Third-party Angular libraries usually need their own major bump to match; pick the release that supports this Angular version.
